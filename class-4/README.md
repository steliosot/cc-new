### Week 4: Validation and Authentication

In Week 4, you will add validation and authentication to a FastAPI application.

Complete the tasks in this order:

1. [Part 1: Validation with Pydantic](lab/part-1.md)
2. [Part 2: Users, Passwords, and Login](lab/part-2.md)
3. [Part 3: Protect API Routes with JWT](lab/part-3.md)

#### What You Need To Do

- Create a FastAPI authentication project in VS Code.
- Use Pydantic schemas for validation.
- Create a users table.
- Hash passwords before storing them.
- Create register and login endpoints.
- Generate JWT access tokens.
- Protect routes using a token.
- Test everything in FastAPI docs.
