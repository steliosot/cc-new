### Week 4 Quiz

`quizmd` is a command-line interface (CLI) for running interactive quizzes in the lab.

Install it inside your active Python environment:

```bash
pip install quizmd
```

Run the Week 4 quiz:

```bash
quizmd quizmd-files/week-4-auth-quiz.md
```

Use a theme if needed:

```bash
quizmd --theme light quizmd-files/week-4-auth-quiz.md
quizmd --theme dark quizmd-files/week-4-auth-quiz.md
```
