### Week 0: GCP Setup and Python Environment

In Week 0, you will prepare your Google Cloud Platform (GCP) account, create your first virtual machine, and set up a small Python environment for future FastAPI work.

Complete the tasks in this order:

1. [Part 1: GCP Coupon and First Virtual Machine](c0-01-part-1.md)
2. [Part 2: Python Virtual Environment](c0-02-part-2.md)

#### What You Need To Do

- Request and redeem your GCP coupon.
- Create a GCP project.
- Enable Compute Engine.
- Create an Ubuntu virtual machine.
- Connect to the VM using SSH.
- Create a small Python virtual environment.
- Create a `requirements.txt` file.
- Install `fastapi` and `uvicorn`.
- Delete the VM when you finish.

> [!WARNING]
>
> Do not leave cloud resources running when you are not using them. Running resources can spend your coupon credit.
