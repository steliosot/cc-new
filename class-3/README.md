### Week 3: FastAPI with SQL

In Week 3, you will connect FastAPI to a SQL database.

Complete the tasks in this order:

1. [Part 1: SQL Database Setup](c3-01-part-1.md)
2. [Part 2: Read Data from SQL](c3-02-part-2.md)
3. [Part 3: MiniPost CRUD API](c3-03-part-3.md)
4. [Quiz 1](c3-04-quiz-1.md)

#### What You Need To Do

- Create a FastAPI project in VS Code.
- Create a `requirements.txt` file.
- Install `fastapi`, `uvicorn`, and `sqlalchemy`.
- Create a SQLite database.
- Create SQLAlchemy models.
- Read database records through API endpoints.
- Use FastAPI docs to test `POST`, `PATCH`, and `DELETE`.
- Build a small CRUD API.
- Complete the Week 3 quiz.
