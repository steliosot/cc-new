### Week 3 Quiz

`quizmd` is a command-line interface (CLI) for running interactive quizzes in the lab.

Install it inside your active Python environment:

```bash
pip install quizmd
```

Run the Week 3 quiz:

```bash
quizmd quizmd-files/week-3-sql-quiz.md
```

Use a theme if needed:

```bash
quizmd --theme light quizmd-files/week-3-sql-quiz.md
quizmd --theme dark quizmd-files/week-3-sql-quiz.md
```
