### Week 2 Quiz

`quizmd` is a command-line interface (CLI) for running interactive quizzes in the lab.

Install it inside your active Python environment:

```bash
pip install quizmd
```

Run the Week 2 quiz:

```bash
quizmd quizmd-files/week-2-fastapi-quiz.md
```

If your terminal has a light background, you can use:

```bash
quizmd --theme light quizmd-files/week-2-fastapi-quiz.md
```

If your terminal has a dark background, you can use:

```bash
quizmd --theme dark quizmd-files/week-2-fastapi-quiz.md
```
